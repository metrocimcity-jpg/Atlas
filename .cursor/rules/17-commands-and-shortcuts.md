# Commands and Keyboard Shortcuts

Recommended commands:

```text
Open Folder
Open JSON
Rescan
Export JSON
Export CSV
Search Files
Clear Filters
Reset Visualization
Toggle Dark Mode
Toggle Details
Toggle Filters
Change Grouping
Change Coloring
Change Size Mapping
Find Duplicates
Open Settings
Command Palette
Save Workspace
Load Workspace
```

Recommended shortcuts:

```text
Ctrl+O        Open Folder
Ctrl+Shift+O  Open JSON
Ctrl+F        Search
Ctrl+K        Command Palette
Esc           Clear selection / close overlay
Backspace     Navigate back
Enter         Open selected item
Ctrl+R        Refresh/rescan
```

Do not override browser/OS shortcuts unless there is a clear product reason.
