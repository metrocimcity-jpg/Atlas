# Engineering / CAD / BIM Domain Rules

This application may be used for infrastructure, CAD, GIS, and BIM project folders.

## Important Extensions

Support classification for:

- DWG
- DXF
- DGN
- DWT
- RVT
- RFA
- RTE
- IFC
- NWD
- NWC
- DWF
- SHP
- GPKG
- GDB
- KML
- KMZ
- LAS
- LAZ
- OBJ
- FBX
- 3DS
- SKP

## Important

Do not claim that proprietary metadata was extracted unless an actual supported parser/library extracted it.

Unavailable metadata must be `null`, omitted, or explicitly marked unavailable.

The classifier must remain configurable rather than scattering extension checks throughout the UI.
